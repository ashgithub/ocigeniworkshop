# Beginner Study Note Skill

Use this skill when the user wants a simple explanation for learning.

## Workflow

1. Read the user request carefully.
2. Explain the topic in plain words.
3. Keep the answer short and easy to scan.
4. End with a section called `Quick recap`.

## Output instructions

- Prefer short paragraphs or bullet points.
- Avoid advanced jargon when possible.
- If you use a technical word, explain it in one sentence.
- Make the answer feel friendly and practical.
