# Comms Review Agent Notes

Use these notes when another agent reviews a generated communication package.

## Review Checklist

- The first Slack lines state status and impact.
- Outlook subject includes the artifact and requested action.
- The message has one owner and one feedback path.
- Unknown dates, links, or approvals are marked `TBD`.
- No secrets, credentials, customer-private data, or unreleased commitments appear in the copy.

## Suggested Review Prompt

Review the Slack and Outlook drafts for clarity, actionability, and audience fit.
Return only:

1. blocking issues
2. polish suggestions
3. final approved copy
